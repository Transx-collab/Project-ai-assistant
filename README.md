# Project AI Assistant — Version 1

### Install
```bash
python -m pip install -r requirements.txt
```

### Run
```bash
streamlit run app.py
```

Then open the local address shown by Streamlit.

### Test
Add a project and ask:
- What is the status?
- What material is pending?
- How many workers?
- What are the issues?
- What is the target and actual progress?

### Next
Version 2 will add Excel import, daily progress, PDF/document search, photos, voice and a real AI model.
